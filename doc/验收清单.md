## 输入与架构

- [x] 当前实现使用 TypeScript + OOP，一类一文件，字段封装和多态。
- [x] `npm run cli` 启动，交互提示符为 `svg>`，EOF 退出。
- [x] 整行注释、双引号及空格参数；颜色中的 # 不丢失。
- [x] 错误统一 `error:`，一条一行，失败后继续处理。
- [x] 按名字分派只出现在命令入口与图形工厂，文档记录待重构项。
- [x] 当前 Composite 统一叶子和容器操作，Command 完成编辑历史。

## 文档与显示

- [x] init 默认 800×600，也支持指定尺寸。
- [x] 当前已实现的文档相关命令在未 init/read 时按要求报错。
- [x] canvas 查询与修改；只在修改时触发历史屏障。
- [x] help 显示全部命令规划并区分实现状态；tree 内联几何属性及层级；show 显示父节点和属性。

## 图形编辑

- [x] create 支持 rect/circle/ellipse/line/text/g；其他类型报指定错误。
- [x] create 尾部 in 指定已有容器；缺失与非容器分别报错。
- [x] id 全局唯一且大小写敏感。
- [x] move 增量平移；分组整体移动。
- [x] scale 系数为正且有限，位置和尺寸都缩放；分组递归。
- [x] set 仅白名单；text 修改子文本；几何属性按类型校验。
- [x] delete 删除完整子树。
- [x] group 收编已有图形并保持约定顺序，拒绝重复目标及祖孙冲突。
- [x] ungroup 将孩子提升并保持位置；拒绝根级容器解组。
- [x] addto 追加到末尾；拒绝将容器放进自身或其后代。
- [x] front/back 只改变同级 z-order，语义与 SVG 绘制顺序一致。

## 历史与事务

- [x] 每条编辑一个 undo 单元，包括 group/delete 等树操作。
- [x] undo 恢复原父容器、原顺序、子树、几何和 id 索引。
- [x] 当前 create 的 redo 恢复执行结果；undo 后新的成功编辑清空 redo。
- [x] tree/show/help 不进入或清空历史。
- [ ] 成功 init/read/save/canvas 修改后禁止 undo/redo，直到下一次成功编辑。
- [ ] 所有失败命令均不改变文档、历史、路径及屏障状态。

## 文件

- [x] save 输出浏览器可打开的 SVG，包括文本与属性转义。
- [x] save 无参数时使用关联文件路径，缺路径时明确报错。
- [ ] read 支持六种类型和嵌套；缺失 id 自动补全、避开已有 id 并警告。
- [ ] 重复 id、损坏 XML、不可读写路径按约定处理，失败不替换现有文档。
- [ ] save/read 往返后画布、几何、样式、文字、层级及顺序一致。
- [ ] 外部 transform、未知标签和属性的支持范围已明确并验证。
