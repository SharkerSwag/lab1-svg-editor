## 图形编辑

- [x] create 支持 rect/circle/ellipse/line/text/g；其他类型报指定错误。
- [x] create 尾部 in 指定已有容器；缺失与非容器分别报错。
- [x] id 全局唯一且大小写敏感。
- [x] move 增量平移；分组整体移动。
- [x] scale 系数为正且有限，位置和尺寸都缩放；分组递归。
- [x] set 仅白名单；text 修改子文本；几何属性按类型校验。
- [x] delete 删除完整子树。
- [x] group 收编已有图形并保持约定顺序，拒绝重复目标及祖孙冲突。
- [x] ungroup 将孩子提升并保持位置；拒绝根级容器解组。
- [x] addto 追加到末尾；拒绝将容器放进自身或其后代。
- [x] front/back 只改变同级 z-order，语义与 SVG 绘制顺序一致。

## 历史与事务

- [x] 每条编辑一个 undo 单元，包括 group/delete 等树操作。
- [x] undo 恢复原父容器、原顺序、子树、几何和 id 索引。
- [x] 全部编辑的 redo 恢复执行结果；undo 后新的成功编辑清空 redo。
- [x] tree/show/help 不进入或清空历史。
- [x] 成功 init/read/save/canvas 修改后禁止 undo/redo，直到下一次成功编辑。
- [x] 所有已实现命令的失败路径均不改变文档、历史、路径及屏障状态。

## 文件

- [x] read 后无参数 save 保持写回读入路径，显式导出不重定向默认目标；缺路径时明确报错。
- [x] read 支持六种类型和嵌套；缺失 id 自动补全、避开已有 id 并警告。
- [x] 重复 id、损坏 XML、不可读写路径按约定处理，失败不替换现有文档。
- [x] save/read 往返后画布、几何、样式、文字、层级及顺序一致。
- [x] 不支持的编码声明明确拒绝；失败导入保留文档、路径和 redo。
- [x] 外部 transform、未知标签和属性的支持范围已明确并验证。
